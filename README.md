## ✨ Features
- **Celestial Carbon & Violet-Cyan UI**: Smooth rounded surfaces, custom typography, and unified app-wide theming.
- **Custom Animated Bottom Navigation**: Spring-animated vector canvas icons across Home, Library, Updates, Browse, and More.
- **Floating Reader HUD**: Rounded top & bottom control decks with live chapter progress bar and pill page indicator.
- **Zero-Knowledge Cloud Accounts (	sukiyomi_accounts)**: Sync your library, reading history, chapters, categories, and settings across devices with unique usernames and client-side PBKDF2-HMAC-SHA256 + AES-256-GCM encryption.
- **In-App Updater**: Check and install new releases directly from **More -> Check for updates**.
